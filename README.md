# Rohan local server files

This repository contains the XAMPP `htdocs` files (excluding XAMPP's `default` folder and local `.bak` backups), plus the Rohan registry and client launch files.

## Credentials

Database credentials in `htdocs/Member/config.php`, `htdocs/RohanAuth/config.php`, and `ROHAN/rohan-reg/rohan.reg` have been replaced with `CHANGE_ME`. Fill in your own local settings before use. The registry file is a template for the local machine and is not ready to import as-is.

The included web, launcher, and patch files are provided by the repository owner. Use only where you have the rights and licenses to do so.
